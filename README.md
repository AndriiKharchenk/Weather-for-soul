## ✨ Особливості

- 🌍 **Реальні дані погоди** від OpenWeather API
- 💬 **Щоденні гумористичні поради** залежно від погоди і сезону
- ⏱️ **Почасовий прогноз** і прогноз на 5 днів
- 🖼️ **Динамічний фон** змінюється по сезону
- ❄️ **CSS ефекти** снігу та грози
- 🌡️ **Перемикання °C / °F**
- 🌐 **Дві мови** — UA / EN
- 📍 **Геолокація** — автоматично визначає місто
- 💾 **Запам'ятовує** останнє місто
- 📱 **PWA** — встановлюється як додаток
- 🔌 **Офлайн режим** — працює без інтернету

## 🛠️ Технології

| Технологія | Опис |
|---|---|
| Vanilla JavaScript | Без фреймворків |
| OpenWeather API | Дані погоди |
| CSS Glassmorphism | Дизайн інтерфейсу |
| Service Worker | PWA + офлайн |
| CSS Animations | Ефекти погоди |
