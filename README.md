# Weather for Soul 🌤️

PWA погодний застосунок з щоденними порадами прив'язаними до погоди.

## Особливості<img width="4063" height="2101" alt="Frame 4" src="https://github.com/user-attachments/assets/81915b2b-3fb9-4bb9-9861-c4d733f6bff0" />

- Реальні дані погоди від OpenWeather API
- Щоденні гумористичні поради залежно від погоди і сезону
- Почасовий прогноз і прогноз на 5 днів
- Динамічний фон змінюється по сезону і погоді
- Перемикання °C / °F
- Два мови — UA / EN
- Запам'ятовує останнє місто

## Технології
- Vanilla JavaScript
- OpenWeather API
- CSS Glassmorphism
- PWA
